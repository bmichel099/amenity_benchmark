Amenity Ecosystem

Benchmark the amenity mix of places worldwide. Describe a location type and Gemini suggests comparable real-world examples plus a custom set of amenity groups; the app pulls every shop & amenity from OpenStreetMap inside each boundary and renders a normalised bubble chart so you can compare the “ecosystem” across locations.

Three ways to add locations

  • AI Search — describe a place type (e.g. “boutique design district”) and pick how many benchmarks to generate.
  • OSM IDs — paste specific OpenStreetMap relation or way IDs.
  • Draw — draw your own boundary polygon and name it.

Tips

  • Right-click any polygon to edit its vertices.
  • Click Analyse to fetch amenities, then download the chart (SVG) or the raw amenities (GeoJSON).
Population Estimate

Estimate the population living inside any set of areas using the GHSL 100 m (2025) global population raster. Population is summed per area with exact partial-pixel coverage.

Define areas in three ways

  • Draw polygon — click to place vertices, double-click to finish.
  • Circle buffer — drag a circular buffer from a point; the radius (km) shows live and stays editable.
  • Upload shapefile — a zipped shapefile/GeoJSON; point layers prompt for a buffer radius.

Tips

  • Right-click a polygon to edit its vertices; drag a circle’s handle to resize.
  • Click Estimate population, then download results as GeoJSON, CSV, or Shapefile with the population attributes appended.
